#  solveEVP

Solve an EVP and return a native-basis solution set.


---

## Declaration
```matlab
 basisSet = solveEVP(solver,evp,options)
```
## Parameters
+ `evp`  physical-coordinate EVP descriptor
+ `options.nModes`  number of modes to retain

## Returns
+ `basisSet`  solved native basis set
