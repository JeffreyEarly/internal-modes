#  IMSolverFiniteDifference

Create a finite-difference solver from a physical grid.


---

## Declaration
```matlab
 solver = IMSolverFiniteDifference(options)
```
## Parameters
+ `options.z`  finite-difference grid
+ `options.N2`  buoyancy frequency squared function

## Returns
+ `solver`  initialized finite-difference solver
