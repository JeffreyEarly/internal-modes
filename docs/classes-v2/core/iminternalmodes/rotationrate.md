#  rotationRate

Planetary rotation rate in radians per second.


---

## Discussion

The default is Earth rotation, $$7.2921\times10^{-5}\ \mathrm{rad\,s^{-1}}$$.
Set `rotationRate=0` for a nonrotating problem and the original
`wkb` coordinate $$dx/dz=N$$.
