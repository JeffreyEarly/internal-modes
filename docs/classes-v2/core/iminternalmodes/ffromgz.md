#  FfromGz

Diagnostic relation from `G` derivative to `F`.


---

## Discussion

  `FfromGz` has signature `F = FfromGz(z,dGdz,h,ctx)`. The default
  relation is
  $$F_j(z)=h_j\frac{\partial G_j}{\partial z}(z).$$
