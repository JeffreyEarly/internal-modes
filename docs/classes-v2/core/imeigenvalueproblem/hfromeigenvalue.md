#  hFromEigenvalue

Equivalent-depth conversion function.


---

## Discussion

  `hFromEigenvalue` maps retained eigenvalues to the equivalent
  depths stored on the returned basis set. The handle has signature
  `h = hFromEigenvalue(lambda)`.
