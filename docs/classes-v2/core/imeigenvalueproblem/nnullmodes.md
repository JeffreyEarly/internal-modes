#  nNullModes

Number of true null modes.


---

## Discussion

  Null modes are zero-eigenvalue modes selected after boundary
  modes and before positive interior modes. In the hydrostatic `F`
  EVP, this is the depth-uniform mode with $$F_0(z)=1$$ and
  $$G_0(z)=0$$.
