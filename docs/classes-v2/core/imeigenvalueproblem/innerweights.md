#  innerWeights

Inner-product weights for `F` and `G`.


---

## Discussion

  Each field stores the interior weight in
  $$\int w(z)X_i(z)X_j(z)\,dz$$ for variable `F` or `G`. Boundary
  trace terms are stored on boundary conditions.
