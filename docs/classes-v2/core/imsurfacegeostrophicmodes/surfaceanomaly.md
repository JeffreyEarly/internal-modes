#  surfaceAnomaly

Surface anomaly convention.


---

## Discussion

  `surfaceAnomaly` is `"freeSurface"` or `"noFreeSurface"`.
  The default includes the free-surface stretching term
  $$-f_0F(0)/g$$ in the surface anomaly.
