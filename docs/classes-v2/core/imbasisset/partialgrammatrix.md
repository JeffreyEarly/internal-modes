#  partialGramMatrix

Return a partial-domain scalar Gram matrix.


---

## Declaration
```matlab
 gram = partialGramMatrix(basisSet,variable,zMin,zMax)
```
## Parameters
+ `variable`  scalar variable name, `"u"`
+ `zMin`  lower physical bound
+ `zMax`  upper physical bound

## Returns
+ `gram`  scalar Gram matrix
