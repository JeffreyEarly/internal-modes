#  quadraturePoints

Return a full-depth grid generated by the next selected mode.


---

## Declaration
```matlab
 z = quadraturePoints(basisSet,options)
```
## Parameters
+ `options.nModes`  number of leading retained modes represented by the grid

## Returns
+ `z`  increasing full-depth mode-root grid

## Discussion

For the first $$N$$ retained scalar modes, `quadraturePoints` uses the
next selected mode $$u_{N+1}$$ and returns

$$
\mathbf{z}_q=\{z_b\}\cup
\left\{z\in(z_b,z_s):u_{N+1}(z)=0\right\}\cup\{z_s\}.
$$

Here `nModes=N` counts the same retained column prefix used by
`discreteTransform`; it is not interpreted as a physical `modeNumber`.
If the generating column was not retained, the stored solver and EVP are
used to solve for one additional mode without changing this basis set.
The returned grid is a canonical candidate whose quadrature increments
and Gram accuracy should still be assessed with `fitQuadrature`.

```matlab
z = basisSet.quadraturePoints(nModes=8);
fit = basisSet.fitQuadrature(z=z,nModes=8);
transform = fit.fittedTransform;
```
