#  gramMatrix

Return a Gram matrix for exact `F` or `G` modes.


---

## Declaration
```matlab
 gram = gramMatrix(basisSet,options)
```
## Parameters
+ `options.variable`  `"F"` or `"G"`
+ `options.zBounds`  integration bounds

## Returns
+ `gram`  Gram matrix
