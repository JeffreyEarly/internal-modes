#  summarize

Print a readable summary of the analytical solution.


---

## Declaration
```matlab
 summarize(solution,evp)
```
## Parameters
+ `evp`  optional internal-mode EVP

## Discussion

With an EVP input, the summary also reports internal-mode
availability for that problem.
